Ölçeg subutnama.

A redesign of the railway loading trainer, taken back to the thing it teaches from: the printed plate. Every figure on screen is a figure off a table, and the interface says which table. Nothing is drawn to a size the handbook does not give.

Ground inverted — plates are printed on paper.
Olive demoted from field to accent.

Esas 01

The interface was hiding its own evidence.

Figures without provenance

A stop block is 200 mm wide because Table 3 says so for a vehicle in the 12,0 t bracket. The old screens printed the number and dropped the source, so a trainee could not tell a handbook figure from a drawn approximation. In the new model every value carries the row it came from.

State carried by colour alone

Correct, configured and not-yet-configured were sand, green and amber — the hardest triple to separate on a projector, in print, or with a colour vision deficiency. Every state now has a shape and a word as well as a hue.

Unconfirmed is not a failure. Where the extracted handbook data cannot establish eligibility, the option is still offered and marked tassyklanmadyk. Hiding it would teach the trainee that the choice does not exist; asserting it would invent a figure. Neither is acceptable.

Ekranlar 04

Placement, and the review that follows it

Step 04 is where the work happens: the trainee seats the blocks themselves. Step 05 therefore reports rather than asks — a decision already made by hand is never put back as a written question.

Geçiriş 06

Porting to Flutter

Nothing here needs a new architecture. The tokens map onto the classes the application already has, and the components onto widgets that already exist.

AppColors

paper → scaffold
surface → card
olive → primary
verdant / amber / oxide → semantic

AppText

Archivo → display, titles
Plex Sans → body, labels
Plex Mono → every figure

AppSpace

Already built — 4 / 8 / 12 / 16 / 24 / 32, unchanged

Components

VerdictChip → chip
AppPanel → eq card
SectionHeading → sect-head
dimension callout → new

The one genuinely new thing is the dimension callout — the tick, extension line and monospaced value that names a measurement. It is how the source plates annotate, and it is what would make the application look like it came from the handbook rather than from a UI kit.
